# Gebetszeiten-Widget (iOS)

Ein Homescreen-Widget im Stil von islamsalzgitter.de/gebetszeiten. Es zeigt das aktuelle und das nächste Gebet.

1. **Scriptable** aus dem App Store installieren (kostenlos).
2. In Scriptable auf **+** tippen, den Inhalt von `Gebetszeiten.js` einfügen und das Script „Gebetszeiten“ nennen.
3. Homescreen lang drücken → **+** → *Scriptable* → Größe **Mittel** wählen (beide Karten) oder **Klein** (nur nächstes Gebet).
4. Das Widget lang drücken → *Widget bearbeiten* → als Script **Gebetszeiten** wählen.

Die Zeiten kommen ausschließlich von der Gebetszeiten-App der Moschee (`admin-ajax.php?action=ptcms_load`), keine eigene Berechnung. Die Jahrestabelle wird einmal täglich geladen und zwischengespeichert, das Widget funktioniert also auch offline. Optik: Liquid Glass – am besten mit dem Homescreen-Stil „Klar“.
